# Experiment note template

Use this template for each sandbox experiment so another person can reproduce the result without relying on chat history.

## Goal

State the behavior or question being tested in one sentence.

## Scope and constraints

Record the repository revision, runtime or tool versions, operating system, and any data or network limits that affect the result.

## Reproduction

List the smallest command sequence or UI steps that reproduces the behavior. Keep secrets and private data out of the note.

## Expected result

Describe the observable result that would confirm the hypothesis.

## Observed result

Record what actually happened, including errors, timestamps, and relevant output.

## Verification

List the focused checks that support the conclusion (for example, a test command, a diff, or a screenshot). Separate verified facts from follow-up questions.

## Cleanup

Describe temporary files, branches, services, or other state that should be removed after the experiment.

## Attribution

Record the author and any real co-authors of the change. Use a standard `Co-authored-by:` trailer in the commit message when a second contributor made a material contribution.
